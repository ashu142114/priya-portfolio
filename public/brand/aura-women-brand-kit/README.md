# Asset Convention for Brand Kit: aura-women-brand-kit

Drop the following exact files into this directory:
- `logo.svg` - Primary vector brand logo
- `palette.png` - Color swatch palette presentation
- `typography.png` - Type specimen hierarchy sheet
- `mockup-1.png` - Primary brand collateral mockup (e.g. Stationery, letterhead)
- `mockup-2.png` - Secondary brand collateral mockup (e.g. Social suite, business cards)

*Note: The website automatically renders live CSS/SVG brand boards if assets are missing.*
