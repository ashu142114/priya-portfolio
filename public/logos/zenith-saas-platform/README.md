# Asset Convention for Logo: zenith-saas-platform

Drop the following exact files into this directory:
- `logo-old.svg` (or .png) - Previous / legacy logo mark
- `logo-new.svg` (or .png) - Redesigned vector logo mark
- `concept.png` - Logo sketch, golden-ratio grid, or geometry concept sheet

*Note: The website automatically falls back to an elegant vector logo mark placeholder if not provided.*
