# Asset Convention for Graphic Design: clinical-wellness-brochure

Drop the following exact files into this directory:
- `banner.png` - Digital display banner or web hero
- `flyer.png` - Promotional marketing flyer
- `brochure.png` - Tri-fold or multi-page brochure
- `business-card.png` - Front and back business card mockup
- `invitation.png` - Event invitation card
- `social-post.png` - Instagram / LinkedIn post creative

*Note: The website automatically displays an interactive preview frame when image files are awaiting upload.*
