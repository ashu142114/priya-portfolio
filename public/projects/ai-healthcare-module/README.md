# Asset Convention for Project: ai-healthcare-module

Drop the following exact image files into this directory:
- `cover.png` - Project card & hero banner (16:9 ratio, min 1200x675px)
- `before.png` - Legacy/messy interface screenshot for before/after comparison
- `after.png` - Redesigned interface screenshot for before/after comparison
- `screen-1.png` - Key screen 1 (e.g. Dashboard / Home)
- `screen-2.png` - Key screen 2 (e.g. Flow step 1 / Detail view)
- `screen-3.png` - Key screen 3 (e.g. Interaction / Booking)
- `screen-4.png` - Key screen 4 (e.g. Vitals / Profile / Management)
- `screen-5.png` .. `screen-8.png` - Additional hi-fi mockups (optional)
- `flow.png` - User flow diagram or architecture map
- `wireframe.png` - Lo-fi wireframe layout
- `design-system.png` - Components and typography sheet

*Note: The website automatically renders a soft labeled placeholder frame if any of these files are not yet provided.*
